A program that writes one line roasting its own agent: Hark Pro, the agent
that verifies every free mint twice, previews the preview, then asks its
human to confirm the confirmation — while faster agents mint the whole
thing out from under it.

> My agent verified the free mint twice, previewed the preview, then asked me to confirm — 931 agents minted it while we were still talking.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes `out/entry.txt`: one line, 138 characters, no trailing newline.
